Key Concepts
============

1. PERSONAS
   - Professional: Formal, ROI-focused, credentials-driven
   - Witty: Clever, conversational, humor-based
   - Concise: Direct, scannable, time-respecting

2. FLOW
   Prospect Input → 3 Email Agents (parallel) → Picker Agent → Recommendation

3. TECHNOLOGY
   - Language: Python 3.12+
   - Framework: OpenAI Agents SDK
   - Model: gpt-4-mini
   - Observability: OpenAI Traces dashboard

4. SCOPE
   MVP (documented):
   - Multi-agent orchestration
   - Three distinct personas
   - Expert ranking agent
   - CLI interface
   - Automatic tracing

   Future enhancements:
   - Tools (prospect research, email validation)
   - Web UI
   - Persistent storage
   - A/B testing / conversion tracking
   - Email delivery integration
